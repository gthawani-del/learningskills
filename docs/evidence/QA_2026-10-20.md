- PR #9 recovery and PR #10 attachment/resumable-ingestion/inspection changes are not merged into this production revision. Latest PR #10 preview `https://learningskills-cr3njokfb-ggg12.vercel.app` is READY at `7a43483e6701712f17bde1dc8915636ac25dfd35`; exact-commit Actions run 39392450811 succeeded.
- Latest preview redirects to Vercel login. Connected protected-fetch helper returned 403 at read_protection_bypass. Approval was requested for a 15-minute preview QA access link; no access-control settings were changed.
- Vercel project/deployment management **works when no explicit team scope is forced**. Earlier team-scoped 403 results do not mean the owner connection is unavailable.
- Real sign-in/recovery emails, two-account isolation, private cloud uploads and cross-browser cloud persistence remain untested: no designated account credentials are available in this runtime.
- No paid model calls, real song-analysis/lip-sync quality checks, billing reconciliation, hosted finished-film rendering or production pilots were performed.
- Physical mobile devices and assistive technologies were not tested.
- Chromium initially rejected the execution environment's certificate trust. An isolated test context used ignore_https_errors for public/signed-out checks. This is not certificate-chain validation; no server TLS or Vercel protection settings were changed.
